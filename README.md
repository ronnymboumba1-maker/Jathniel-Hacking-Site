# ⚡ JATHNIEL SECURITY HACKING ETHICAL

![Version](https://img.shields.io/badge/version-2.4.0-blue)
![Node](https://img.shields.io/badge/Node.js-18.x-green)

> Plateforme interactive d'apprentissage du hacking éthique. Apprenez en vous amusant avec une console réaliste, un système de progression et un leaderboard !

---

## 🎯 **Fonctionnalités**

| Fonctionnalité | Description |
|----------------|-------------|
| 🎮 **Console interactive** | Tapez `scan`, `exploit`, `reverse` comme un vrai hacker |
| 📈 **Progression XP** | Gagnez de l'XP à chaque commande, montez de niveau |
| 🏆 **Leaderboard** | Comparez votre progression avec les autres |
| 💾 **Sauvegarde auto** | Votre compte et vos stats sont sauvegardés |
| 🔐 **Authentification** | Créez votre compte et connectez-vous |

---

## 🚀 **Commandes disponibles**

| Commande | Effet |
|----------|-------|
| `help` | Affiche toutes les commandes |
| `scan` | Simule un scan réseau Nmap |
| `exploit` | Lance une exploitation de faille |
| `reverse` | Établit un reverse shell |
| `unlock` | Débloque des modules avancés |
| `status` | Voir votre progression |
| `clear` | Nettoie la console |

---

## 🛠️ **Technologies utilisées**

- **Frontend** : HTML5, CSS3, JavaScript, GSAP
- **Backend** : Node.js, Express
- **Base de données** : SQLite
- **Hébergement** : Render.com
